# B站收藏管理（bilibili-collector）

一个**本地桌面应用**，用来整理、管理你收藏的 B 站视频。做它的初衷很简单：B 站收藏夹越来越乱、想找某条视频翻半天，于是想要一个「自己的、本地的、能搜索打标签」的收藏管理器。

> 说明：这是一个**个人自用**的收藏整理工具，**不是** B 站第三方客户端，也不复刻 B 站的播放功能。数据全部存在本地，不经过任何服务器。

---

## 主要功能

### 核心功能

- **粘贴链接自动抓取**：粘贴一个 B 站视频链接，自动抓取标题、封面、BV 号、UP 主名字与头像、播放量/弹幕/点赞等数据、视频时长、简介、投稿时间与分区（只抓公开页面的元信息，无需登录、无需 Cookie）
- **本地存储**：所有收藏数据存在本地 SQLite 文件里，关掉重开不丢，数据不经过任何服务器
- **列表展示与搜索**：收藏的视频以列表展示，支持按标题 / BV 号 / 链接 / 标签模糊搜索
- **标签分类**：给收藏打标签，自动聚合成可点击的标签胶囊，点一下即可筛选
- **追番标记**：勾选「看过 / 没看」，配合「全部 / 未看 / 已看」三态筛选，当追番清单用
- **一键跳转**：点标题用网页端打开，顶部按钮直接拉起 B 站桌面客户端（没装客户端会自动退回网页版）

### v1.0 新增：登录 + 收藏夹导入

- **登录 B 站**：应用内弹出登录窗，扫码登录即可，Cookie 安全地存在 Electron 会话里（重启应用登录态仍在）
- **一键导入收藏夹**：登录后列出你的所有收藏夹，选一个即可分页拉取全部视频入库，自动跳过已存在的条目

## 安装与使用

### 方式一：直接下载（推荐给普通用户）

到 [Releases](../../releases) 页面下载最新的 `.exe` 安装包，双击安装即可。当前仅提供 Windows 版本。

### 方式二：从源码运行（开发者）

```bash
# 1. 安装依赖（国内网络可加镜像）
npm install

# 2. 开发模式启动（会弹出窗口）
npm run dev

# 3. 打包成 exe（需要 electron-builder）
npm run package
```

> 首次安装若 Electron 下载慢，可先设置镜像：
> ```bash
> export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
> export npm_config_registry="https://registry.npmmirror.com"
> ```

## 注意事项（请务必阅读）

### 1. 抓取合规边界

- **单条手动抓取**：只请求「公开视频页面」，只提取 `<meta>` 标签里 `og:` 元信息，以及页面自带的 `__INITIAL_STATE__` 公开数据。这些是任何未登录用户打开网页都能看到的内容，不涉及你的账号与隐私。
- **登录导入走官方接口**：登录后的一键导入，走的是 B 站网页端自用的收藏夹接口（`/x/v3/fav/resource/list`），本质是「用你自己的 Cookie 拉你自己的收藏夹」，属于合理自用，风险远低于批量爬公开页面。

### 2. 登录与 Cookie 安全

- 登录产生的 `SESSDATA` 等 Cookie 是**你账号的登录凭证**，请勿把登录态截图发给他人。
- 本项目把 Cookie 存在 Electron 本地会话里，**不写进代码、不上传服务器**。但仍建议：**不要轻易复制粘贴 Cookie 给第三方**。

### 3. 频率控制与风控

- 导入收藏夹时，程序在翻页之间**内置了 1.5 秒延时**，用于控制请求频率、避免触发 B 站风控。**请勿自行调短或移除这个延时**，否则可能触发 `412` 封 IP、弹验证码，甚至导致登录态失效。

### 4. 接口非官方，可能失效

- 收藏夹接口是 B 站网页端**内部接口**（非官方开放 API、无正式文档）。如果 B 站改版或加了签名校验，一键导入功能可能失效，届时需更新适配。

### 5. 封面 / 头像防盗链

- B 站图片域名（`*.hdslb.com`）有防盗链，程序已内置 `Referer` 修复。如果你手动改动了主进程里 `session.webRequest` 相关代码，可能导致封面/头像裂图。

## 项目结构

```
bilibili-collector/
├── src/
│   ├── main/          # Electron 主进程（后端）
│   │   └── index.js   # 窗口创建 + 抓取 + 数据库 + 登录 + 收藏夹导入 + IPC
│   ├── preload/       # 安全桥接层
│   │   └── index.js   # 把后端能力安全地暴露给前端
│   └── renderer/      # React 前端界面
│       ├── index.html
│       └── src/
│           ├── main.jsx
│           ├── App.jsx     # 主界面
│           └── index.css   # 样式（B站粉配色）
├── electron.vite.config.mjs  # electron-vite 配置
├── electron-builder.yml      # 打包配置
└── package.json
```
